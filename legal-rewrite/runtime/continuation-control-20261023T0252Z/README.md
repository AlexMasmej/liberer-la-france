# Poursuite exhaustive demandée par l’utilisateur

Directive humaine : « Continue jusqu’à 100 % sur tous les textes, y compris les différés et les secondes passes, sans sacrifier les vérifications de renvois. »

Ce contrôle maintient l’exécution existante, sans nouveau coordinateur, modification des politiques ou interruption de lot. Il prépare uniquement les preuves de clôture et un transfert futur sous gardes. Le candidat de réaffectation reste hors ligne. Le prototype de contrôleur préparé ce jour reste bloqué avant toute collecte ou mutation de production : ses quinze tests isolés ne remplacent pas le collecteur de réconciliation courant manquant ni les autres garde-fous documentés.

La reprise avec le runner actuel peut reconstruire les différés encore absents de la base au prochain point sûr coordonné, indépendamment de l’installation future des six modules candidats. Le point sûr doit être établi par des preuves actuelles, jamais déduit d’une file absente, d’un compteur ancien ou du seul nombre d’articles couverts. Tous les articles acceptés et toutes les avant-images restent conservés ; aucun différé n’est marqué accepté dans ce contrôle.
