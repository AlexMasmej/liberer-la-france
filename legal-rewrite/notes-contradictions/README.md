# Notes de contradictions

Consigner les contradictions repérées pendant la rédaction, les secondes passes et les contrôles de renvois. Distinguer les divergences des sources officielles, les incohérences introduites par une proposition et les simples alertes non confirmées.

Chaque note précise les articles et versions concernés, les passages incompatibles, les sources de preuve, les conséquences, la correction proposée le cas échéant et le statut de résolution. Ne jamais transformer automatiquement une alerte en erreur juridique établie. Une note permet de poursuivre les travaux indépendants ; elle ne remplace pas la résolution d’un point bloquant ni une validation finale.
