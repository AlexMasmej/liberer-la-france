The site is buildless; dist/ contains all deployed files. build.py regenerates HTML, CSS, metadata, PDF and OG artwork and reads reference-style.css. The bundled fonts in dist/fonts/ are retained across builds.

Validation: JavaScript syntax, contribution ramp and negative-return calculations, browser calculator and definition interactions, all anchors and local assets, five-page PDF visual inspection, live HTML/PDF/OG exact matches. Aggregate transition financing remains to be established.
