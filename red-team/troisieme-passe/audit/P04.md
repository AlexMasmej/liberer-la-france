## Les m

- **P084 — CSS R148-5** (LEGIARTI000037262084, réécrit) — F5, hérité. La proposition désigne deux fois le « médecin-conseil chef de service compétent », alors que R148-2 officiel (décret 2025-599, 1er octobre 2025) et R148-3 proposé désignent le « médecin-conseil responsable du service chargé du contrôle médical de cet organisme ». Deux appellations de la même autorité dans le même chapitre ; R148-6 proposé a la même survivance. Correction minimale : aligner la désignation. Non enregistré au registre.
- **P184 — CSS D412-92** (LEGIARTI000030067856, réécrit) — F7, hérité. La coquille « revenus de remplaçement » de la source est recopiée dans la proposition. Le fond (référence de trente-cinq heures coordonnée avec L3121-27 proposé, L434-16 en deux versions toutes deux proposées) est cohérent. Non enregistré.
- **P304 — travail L4524-1** (LEGIARTI000035652660, maintenu) — F5, hérité, doute à confirmer. La loi institue le comité interentreprises dans le périmètre d'un PPRT « mis en place » ; R4524-1 (source et proposition) le déclenche « lorsqu'un PPRT a été prescrit ». Effet limité ; vérification impossible sans le code de l'environnement, hors corpus. Non enregistré.
- **P524 — CSS L713-19** (LEGIARTI000006744037, maintenu) — F10, notes seulement. Les notes lisent l'état ABROGE_DIFF (1er janvier 2028) comme une abrogation et disent le successeur absent, alors que la version VIGUEUR_DIFF LEGIARTI000054466960 (ordonnance 2026-647, extension à Mayotte) est en production.
