## Défauts mineurs (m), une phrase chacun

- **H052 css D168-11** (F7) : la transition codifiée vise « l'entrée en vigueur du présent décret », une formule sans objet dans un code.
- **H072 cch L321-4** (F10) : la réécriture est purement stylistique ; elle fait passer la faculté de l'Agence (« peut être accordée ») au propriétaire (« peut bénéficier »).
- **H082 css L162-21-3** (F10) : la note dit que D162-10-1 n'est pas modifié, alors qu'il est coordonné.
- **H132 css R162-30** (F3/F4) : le III renvoie à L162-30-2, abrogé par la loi au 1er janvier 2027 (ABROGE_DIFF). Ce renvoi ne survit que par une disposition non codifiée, absente du corpus. Voir RT-FUTCSS-09 : R162-30 n'y figure pas parmi les dépendances.
- **H152 travail L1442-6** (F10) : réécriture à droit constant revendiquée, avec un motif contradictoire (« sans nouvelle reformulation stylistique »).
- **H192 css R133-9-1** (F10) : la note annonce une coordination de R147-2 « hors lot nécessaire », alors qu'elle est déjà faite.
- **H202 css D251-7** (F10) : l'abrogation est justifiée, mais le motif prétend L251-7 absent du corpus, alors qu'il y figure, abrogé depuis 2012.
- **H232 a1 217** (F5) : le principe d'interdiction de la libre circulation des ouvrages à titres non légaux disparaît. Il est remplacé par un renvoi général aux règles du marché intérieur, désormais dans le code de commerce (L834-7, hors corpus). La transition dit « la loi », sans précision.
- **H262 css L921-2-1** (F10) : la note dit la version 2029 de L355-2 « non fournie », alors qu'elle figure au corpus avec une proposition.
- **H282 urba L441-1** (F10) : la note dit la version LEGIARTI000006815771 absente du corpus, alors qu'elle y figure.
- **H292 css R582-5** (F7) : énumération sans conjonction après la suppression des mots sur la pénalité, et « présente réforme » non désignée.
- **H302 travail D3253-5** (F6) : le plafond AGS réduit dépend de la date de « conclusion » du contrat. Or la conversion convenue en contrat unique (L1221-2 proposé) ne garantit que « l'ancienneté et les créances ». Un salarié converti peu avant une procédure collective risque de passer de 6 à 4 ou 5 plafonds. La mise en garde sur la conversion est connue pour le seul préavis (RT-ISS2-01) ; le plafond AGS n'est relevé nulle part. Une correction facultative est proposée dans le JSON.
- **H312 urba L332-17** (F10) : réécriture stylistique à droit constant, que le motif admet.

## Familles observées

F10 : 7 ; F7 : 2 ; F3/F4 : 1 ; F5 : 1 ; F6 : 1. Aucune occurrence de F1, F2, F8 ou F9.

Ce qui se répète :
- les notes affirment qu'une pièce est « absente » ou « non fournie », alors qu'elle figure au corpus ;
- des transitions sont rédigées « à compter du présent décret » ou « de la présente réforme » dans des textes codifiés ;
- des réécritures stylistiques à droit constant sont classées `rewrite_draft`.

Les suppressions de fond de l'échantillon sont bien coordonnées avec leurs textes d'application : rapport du comité économique de l'hospitalisation, pénalité d'intermédiation, majoration L133-4, engagements d'activité partielle, formulaire de l'AJPA, déclaration de circulation de la garantie.
